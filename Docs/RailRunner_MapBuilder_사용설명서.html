RailRunner 맵 서브신 빌더 — 사용 설명서

새 씬에 3D 맵을 만든 상태에서 시작해, 빌더 툴로 재사용 가능한 맵 서브신을 완성하기까지의 전 과정.

도구 메뉴: Tools/RailRunner/Map Builder 출력: Assets/00.Scenes/Maps/<MapId>.unity Unity 2022.3.62f2 / URP

0. 개요

맵은 실시간 구성이 아니라 서브신(additive scene)으로 미리 베이크해 두고 런타임에 로드한다. 라이트맵·오클루전 등 베이크 데이터는 씬에 종속되므로 프리팹이 아닌 씬이 컨테이너가 된다. 빌더 툴이 마커 베이크 → 서브신 Export → Build Settings 등록 → 라이팅 베이크를 한 번에 처리한다.

전제 — 새 씬에 3D 맵(지형·구조물)을 직접 만들었거나 외부에서 가져온 상태. 이 문서는 그 다음부터 다룬다.

1. 완성 목표 구조

최종적으로 만들 맵 루트의 계층 구조다. 모든 월드 콘텐츠는 View_RailMap 루트 아래에 둬야 Export(클론) 대상에 포함된다.

루트/바닥 레일 마커 라이트
그림 1. 맵 서브신 목표 계층 구조
핵심 규칙 — Directional Light를 포함한 모든 요소를 맵 루트의 자식으로 둘 것. Export는 루트 서브트리만 클론한다. 루트 밖에 둔 라이트는 서브신에 안 들어간다.

2. 단계별 가이드

  1. 맵 루트 생성 + View_RailMap 부착

    빈 GameObject를 만들고 이름을 Map_RailRunner로 지정, View_RailMap 컴포넌트를 추가한다. 인스펙터에서 MapId를 설정(런타임 로드 키 = 서브신 파일명).

    • 가져온 3D 맵의 지형·구조물을 이 루트 하위로 이동.

  2. RailPath + 제어점 배치

    루트 자식으로 RailPath GameObject 생성 후 View_RailPath 부착. 그 아래 빈 자식(CP_0…CP_N)을 최소 4개 배치해 곡선 경로를 만든다. 제어점 리스트를 _controlPoints에 연결.

    • 닫힌 곡선(끝→처음 루프). 급격한 꺾임은 피한다.

  3. GridFloor·Markers·Light 부착

    속도 착시 바닥 View_GridFloor(MeshFilter+MeshRenderer 동반), 기준물 View_RailMarkerBaker(RailPath 참조·베이크 부모 연결), Directional Light를 각각 루트 자식으로 추가.

  4. 빌더 창 열기

    상단 메뉴 Tools ▸ RailRunner ▸ Map Builder 선택.

  5. 대상 맵 지정

    창의 ObjectField에 맵 루트를 드래그하거나 “현재 씬에서 자동 탐색” 버튼을 누른다. (씬에서 첫 View_RailMap을 찾아 지정)

  6. 마커 베이크

    “마커 베이크” 클릭. 머티리얼이 없으면 SpeedMarker.mat(URP/Lit)을 자동 생성·할당하고, RailPath를 따라 기둥 구조물을 좌우 교대로 생성한다. 각 마커에 ContributeGI static 플래그가 붙어 라이트맵 대상이 된다. (다시 누르면 기존 마커 제거 후 재생성)

  7. 라이팅 옵션 선택

    “Export 시 라이팅 자동 베이크”를 켜고 라이트 모드를 고른다. 자동 베이크 전에 씬 라이트를 이 모드로 전환한다.

    • Mixed — 베이크 GI + 실시간 직접광/그림자. 동적 캐릭터와 병행(권장).
    • Baked — 완전 베이크. 정적 전용.

  8. 맵 서브신 Export

    “맵 서브신 Export” 클릭. 아래 파이프라인이 한 번에 실행되고 Assets/00.Scenes/Maps/<MapId>.unity가 생성된다.

  9. 완료 확인

    상태 박스에 “Export 완료 + 라이트 … 전환 + 베이크(성공)” 표시. Project 창에서 서브신 파일과 Build Settings 등록을 확인한다. 끝.

7. 트러블슈팅

증상원인 / 해결
“View_RailMarkerBaker 없음”맵 루트 하위에 Markers(베이커) 컴포넌트 누락 → 추가 후 RailPath 연결.
서브신에 라이트 없음Directional Light가 맵 루트 자식이 아님 → 루트 하위로 이동 후 재 Export.
라이트맵이 안 구워짐씬 Lighting의 Baked Global Illumination OFF → ON. 마커는 ContributeGI 자동 설정됨.
마커가 어두움/분홍머티리얼 미할당 → “마커 베이크”가 자동 생성. URP/Lit 셰이더 확인.
런타임 로드 실패MapLoader의 MapId = 서브신 파일명 일치 확인 + Build Settings 등록 여부.
