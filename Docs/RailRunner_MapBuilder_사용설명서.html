RailRunner 맵 서브신 빌더 — 사용 설명서

새 씬에 3D 맵을 만든 상태에서 시작해, 빌더 툴로 재사용 가능한 맵 서브신을 완성하기까지의 전 과정.

도구 메뉴: Tools/RailRunner/Map Builder 출력: Assets/00.Scenes/Maps/<씬이름>.unity Unity 2022.3.62f2 / URP

0. 개요

맵은 실시간 구성이 아니라 서브신(additive scene)으로 미리 베이크해 두고 런타임에 로드한다. 라이트맵·오클루전 등 베이크 데이터는 씬에 종속되므로 프리팹이 아닌 씬이 컨테이너가 된다. 빌더 툴이 제어점 정렬 · 격자 맞춤 · 마커 베이크 · 서브신 Export · Build Settings 등록 · 라이팅 베이크를 처리한다.

전제 — 새 씬에 3D 맵(지형·구조물)을 직접 만들었거나 외부에서 가져온 상태. 이 문서는 그 다음부터 다룬다.

1. 완성 목표 구조

최종적으로 만들 맵 루트의 계층 구조다. 모든 월드 콘텐츠는 View_RailMap 루트 아래에 둬야 Export(클론) 대상에 포함된다.

루트/바닥 레일 마커 라이트
그림 1. 맵 서브신 목표 계층 구조
핵심 규칙 — Directional Light를 포함한 모든 요소를 맵 루트의 자식으로 둘 것. Export는 루트 서브트리만 클론한다. 루트 밖에 둔 라이트는 서브신에 안 들어간다.

2. 단계별 가이드

보라색 번호는 빌더의 편의 도구(수동 작업 대체).

  1. 맵 루트 생성 + View_RailMap 부착

    빈 GameObject를 만들고 View_RailMap 추가, MapId 설정. 가져온 3D 맵의 지형·구조물을 이 루트 하위로 이동.

  2. RailPath + 제어점 배치

    루트 자식으로 RailPath(View_RailPath) 생성. 그 아래 빈 자식 오브젝트를 최소 4개 곡선 형태로 배치한다. 이름/등록은 다음 편의 도구가 처리하므로 위치만 잡으면 된다.

  3. GridFloor · Markers · Light 부착

    View_GridFloor(MeshFilter+MeshRenderer 동반), View_RailMarkerBaker(RailPath 참조·베이크 부모 연결), Directional Light를 각각 루트 자식으로 추가.

  4. 빌더 창 열기

    상단 메뉴 Tools ▸ RailRunner ▸ Map Builder.

  5. 대상 맵 지정

    ObjectField에 맵 루트를 드래그하거나 “현재 씬에서 자동 탐색”. (자동 탐색 시 저장 씬 이름이 비어 있으면 MapId로 채워짐)

  6. 제어점 자동 정렬·등록 편의

    “제어점 자동 정렬·등록 (CP_n)” 클릭. RailPath 자식들을 계층 순서대로 CP_0 … CP_N으로 리네임하고 _controlPoints에 자동 등록·갱신한다. 손으로 리스트에 끌어 넣을 필요 없음. (최소 4개 필요)

  7. 격자 크기 맵에 맞춤 편의

    “격자 여유(m)”를 정한 뒤 “격자 크기 맵에 맞춤” 클릭. RailPath 제어점 + 맵 렌더러를 모두 포함하도록 GridFloor의 크기를 자동 산출한다(격자 중심 기준 최대 반경 + 여유, 칸 크기 배수로 올림).

    • 격자 메시는 로드/플레이 시 재생성 → 저작 씬에선 값만 바뀌고 시각 반영은 Export·실행 후.

  8. 마커 베이크

    “마커 베이크” 클릭. 머티리얼 없으면 SpeedMarker.mat 자동 생성·할당, RailPath 따라 기둥 구조물을 좌우 교대 생성 + ContributeGI static 부여. (재클릭 시 재생성)

  9. 저장 씬 이름 + 라이팅 옵션

    “저장 씬 이름”에 출력 파일명을 입력한다(비우면 MapId→대상 이름 순 폴백). “라이팅 자동 베이크”를 켜고 라이트 모드(Mixed 권장 / Baked)를 고른다.

  10. 맵 서브신 Export

    “맵 서브신 Export” 클릭 → Assets/00.Scenes/Maps/<씬이름>.unity 생성. (아래 파이프라인 자동 실행)

  11. 완료 확인

    상태 박스의 완료 메시지 + Project 창 서브신 파일 + Build Settings 등록 확인. 끝.

주의 — 런타임 로더 View_MapLoader는 씬 이름으로 로드한다. 저장 씬 이름을 MapId와 다르게 지정했다면 로더의 _mapId도 그 이름에 맞춰야 한다.

7. 트러블슈팅

증상원인 / 해결
제어점이 등록 안 됨“제어점 자동 정렬·등록” 미실행, 또는 RailPath 자식 4개 미만 → 자식 추가 후 버튼.
격자가 맵을 못 덮음“격자 크기 맵에 맞춤” 실행. 여유(m)를 키우거나, 멀리 떨어진 렌더러가 바운드를 키우는지 확인.
“View_RailMarkerBaker 없음”맵 루트 하위에 Markers(베이커) 컴포넌트 누락 → 추가 후 RailPath 연결.
서브신에 라이트 없음Directional Light가 맵 루트 자식이 아님 → 루트 하위로 이동 후 재 Export.
라이트맵이 안 구워짐씬 Lighting의 Baked Global Illumination OFF → ON. 마커는 ContributeGI 자동.
런타임 로드 실패로더 _mapId = 저장 씬 이름 일치 확인 + Build Settings 등록 여부.
